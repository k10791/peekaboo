# 피카부 시연
### PC 실행
- 압축 해제 → 폴더에서 py -m http.server 8000
- 열기: http://localhost:8000(새 창 열림)

### 스마트폰 실행
- 세 파일을 HTTPS 정적 호스팅에 올리기
- Safari(아이폰) 또는 Chrome(안드로이드)에서 열기

### 카메라 테스트
- 거리 감지 설정 → 카메라 켜기 → 권한 허용 (30cm 보정)

### 시연
- 영상 열기 → 약 20cm에서 경고 확인
- 약 35cm에서 까꿍 확인

### 가상 거리
- 거리 감지 설정 → 가상 거리 → 20cm, 35cm

### 웹 실행
- main.js: OpenCV.js와 거리 판정 사용
- engine.py: 별도 판정 테스트용으로 사용
